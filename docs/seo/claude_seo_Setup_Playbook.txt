Setting up Tier 1 — Google API Key (Recommended Starting Point)
1. Go to Google Cloud Console
Visit console.cloud.google.com and sign in with your Google account.
2. Create a new project
Click 'Select a project' → 'New Project'. Name it 'claude-seo' for clarity.
3. Enable required APIs
Go to APIs & Services → Library. Enable these 6 free APIs:
→ PageSpeed Insights API
→ Chrome UX Report API
→ YouTube Data API v3
→ Cloud Natural Language API
→ Custom Search API
→ Trends (no explicit enable needed)
4. Create an API key
Go to APIs & Services → Credentials → Create Credentials → API Key.
Restrict the key to the 5 APIs above for security.
5. Add to claude-seo config
Create or edit ~/.claude/skills/claude-seo/config.env:
GOOGLE_API_KEY=your_api_key_here
✓ CONFIRMED WORKING: Google's free tier for these APIs provides ~$300 credit per month. A full site audit typically costs less
than $0.01 in API calls.

Severity levels and how to act on them
■ CRITICAL — Blocks crawling or indexation. Google cannot access or rank these pages. Fix within 48 hours.
Examples: Noindex on key pages, broken canonical chain, disallow in robots.txt on priority URLs, missing sitemap, 5xx server errors on landing
pages.
■ HIGH — Directly impacts rankings or user experience. Fix within 2 weeks.
Examples: Missing or duplicate H1 tags, title tags over 60 chars or missing keyword, Core Web Vitals failing, missing schema on high-traffic pages,
thin content on BOFU pages.
■ MEDIUM — Meaningful opportunity loss. Fix within 30-60 days.
Examples: Missing meta descriptions, internal linking gaps, missing FAQ schema, suboptimal E-E-A-T signals, GEO passage citability score below
threshold.
■ LOW — Nice-to-have improvements. Add to backlog.
Examples: Image alt text improvements, minor heading hierarchy issues, additional schema types, long-tail keyword coverage gaps.

9.  Activating the GEO Sub-Skill for AI Search Visibility
The GEO sub-skill is one of the most unique capabilities of claude-seo. It audits your content specifically for AI search
engine citation — going beyond traditional SEO to assess whether ChatGPT, Perplexity, Gemini, and Google AI Overviews
are likely to cite your content.
What the GEO sub-skill audits
 Passage citability
Identifies 134-167 word self-contained answer blocks. This is the optimal length for AI systems to extract and cite as a direct
answer.
 Question-based heading hierarchy
Audits whether your H2s and H3s are phrased as questions — AI systems use headings to identify answerable content.
 Attribution density
Counts citable, sourced claims per 1,000 words. AI systems prefer content that references primary sources.
 Entity presence tracking
Checks whether your brand and topic entities appear on authoritative third-party sources (Wikipedia, Reddit, YouTube, LinkedIn).
 Structured data coverage
Validates that FAQ, Article, and HowTo schema are present and correctly implemented for AI extractability.
 llms.txt alignment
Checks your llms.txt file (if present) for accuracy. Note: claude-seo's documentation correctly states that llms.txt is currently NOT
a citation lever — this is included as evidence-based guidance.
 AI Overviews eligibility
Checks whether your pages meet the technical requirements to appear in Google AI Overviews (indexed, eligible for snippet
display).
GEO audit commands
 GEO COMMANDS
# Run GEO audit on a single page
/seo geo https://yourdomain.com/your-page
# Run GEO audit across the full site
/seo audit https://yourdomain.com --geo
# GEO + traditional SEO combined
/seo audit https://yourdomain.com --geo --deep
# Request GEO-specific recommendations only
/seo geo https://yourdomain.com/page --recommend
# Check AI Overviews eligibility for a page
/seo geo https://yourdomain.com/page --overviews
METHODOLOGY NOTE: The GEO sub-skill is aligned with Google's AI Optimization Guide and is evidence-based. It correctly
debunks 3 popular myths: llms.txt is not a citation lever, content chunking is not required, and AI-specific keyword rewriting is
unnecessary. Every recommendation includes the primary-source evidence it rests on.

11.  Common Errors and Exactly How to Fix Them
These are the exact errors the community reports most frequently. Each one has a confirmed fix.
■ WARNING: /plugin marketplace add returns 404
Cause: Claude Code version is too old to support the
plugin marketplace.
Fix:
npm install -g @anthropic-ai/claude-code@latest
Then retry the marketplace add.
■ WARNING: 'Plugin not found' after marketplace add
Cause: The plugin needs to be installed after adding.
Fix:
/plugin install claude-seo@agricidaniel-claude-seo
(The marketplace add and plugin install are two separate steps.)
■ WARNING: Python not found or wrong version
Cause: Python 3.10+ is required. System Python may
be 2.x or 3.9.
Fix:
Install Python 3.10+: brew install python@3.10 (macOS) or
apt install python3.10 (Ubuntu).
Then: python3 --version to confirm.
■ WARNING: weasyprint install fails (PDF reports not working)
Cause: weasyprint has system dependencies that pip
alone cannot install.
Fix:
macOS: brew install pango cairo
Ubuntu: apt-get install libpango-1.0-0 libcairo2
Then: pip3 install weasyprint
■ WARNING: Google OAuth error: 'redirect_uri_mismatch'
Cause: OAuth app not configured for desktop/local use.
Fix:
In Google Cloud Console → Credentials → Edit your OAuth client:
Application type must be 'Desktop app', not 'Web application'.
Recreate the credentials if needed.
■ WARNING: GSC data not appearing in audit
Cause: Site not verified in Search Console or OAuth
scope missing.
Fix:
